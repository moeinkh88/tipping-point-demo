Where the tipping point lies

Supplementary companion to the paper. The full model (m, i, h) has one tipping point: the saddle S, a fixed point in three dimensions. An observer who sees only m and i sees something else: the (m, i) dynamics with memory held at its current value. Memory adds the same push η·Φh(h) to dm/dt and di/dt, so each memory level gives a different landscape. Memory-gated (main text): this landscape has a single valley at every memory level and no tipping point at all; the threshold is a level of memory. Directly gated: the landscape has its own tipping point, which memory moves. Drag the time slider and watch the four views together.

Feedback strengths

Above 1, that feedback alone makes the model bistable.

Memory half-life

Time after which memory has lost half of an insult (ln 2 / ε). The equilibria do not change; only how fast h follows m and i.

Model: dm/dt = −α m + β Φ(i) + η Φh(h), di/dt = −α i + β Φ(m) + η Φh(h), dh/dt = γ(m + i) − ε h, with α = 0.05, K = 0.40, n = 3, Kh = 0.38, nh = 4, c = 2γ/ε = 1. β and η are set from the feedback strengths Gmi and Gh (Methods of the paper).
