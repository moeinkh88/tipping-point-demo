Same present, different future

Interactive companion to the paper. Microbial dysbiosis m and immune dysregulation i can be measured; inflammatory memory h is hidden. Section 1 follows two subjects whose insults put them just beyond and just short of their tipping size: for a while they look the same, then they go to opposite states. Section 2 shows a subject who looks recovered but is still vulnerable to a second insult. Change the feedback strengths and the memory half-life to see when memory sets these time scales.

Feedback strengths

Above 1, that feedback alone makes the model bistable.

Memory half-life

Time after which memory has lost half of an insult. Changing it does not move the equilibria.

Each insult is placed a fraction δ beyond (subject 1) or short of (subject 2) its own tipping size.

Model (Eq. 1 of the paper, symmetric parameters): dm/dt = −α m + β Φ(i) + η Φh(h), di/dt = −α i + β Φ(m) + η Φh(h), dh/dt = γ(m + i) − ε h, with α = 0.05 per day, K = 0.40, n = 3, Kh = 0.38, nh = 4, c = 2γ/ε = 1; β and η are set from the feedback strengths Gmi and Gh, and ε from the memory half-life. The parameters are illustrative, not estimates. Insult directions as in the paper; similarity threshold θ = 0.25. Integrated in the browser (RK4).
